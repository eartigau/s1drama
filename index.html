S1D-Rama

APERO-style conversion from 2D extracted echelle orders (s2d / e2ds FITS) to a merged 1D spectrum (s1d FITS table). Conversion à la APERO d'ordres échelle 2D extraits (FITS s2d / e2ds) vers un spectre 1D fusionné (table FITS s1d).

Python 3.12+ NIRPS / APERO Cook et al. 2022 FITS · NumPy · SciPy

Why this existsPourquoi cet outil existe

Many analyses need a single 1D spectrum, but reduced echelle products are naturally 2D (order × pixel). S1D-Rama provides a transparent, script-level implementation of the APERO order-merging logic used to build 1D spectra. Bien des analyses ont besoin d'un spectre 1D unique, mais les produits échelle réduits sont naturellement en 2D (ordre × pixel). S1D-Rama offre une implémentation transparente, au niveau du script, de la logique de fusion des ordres d'APERO utilisée pour construire des spectres 1D.

The merging recipe follows APERO's approach where overlapping orders are combined using blaze-based weighting and edge tapering to avoid discontinuities. La recette de fusion suit l'approche d'APERO : les ordres qui se chevauchent sont combinés à l'aide d'une pondération basée sur la fonction blaze et d'un lissage des bords, afin d'éviter les discontinuités.

AlgorithmAlgorithme

APERO-style order merging in seven steps:Fusion des ordres à la APERO en sept étapes :

  1. Build target 1D wavelength grid (uniform in velocity).Construire la grille de longueur d'onde 1D cible (uniforme en vitesse).
  2. Build edge taper weights per order so order ends fade in/out smoothly.Construire des poids de lissage de bord par ordre, pour que les extrémités s'estompent en douceur.
  3. Multiply flux and blaze by the edge taper.Multiplier le flux et la fonction blaze par le lissage de bord.
  4. Spline each order onto the target 1D grid.Interpoler (spline) chaque ordre sur la grille 1D cible.
  5. Combine overlapping orders using the blaze as weight.Combiner les ordres qui se chevauchent en utilisant la fonction blaze comme poids.
  6. Normalize by total weight in each wavelength bin.Normaliser par le poids total dans chaque intervalle de longueur d'onde.
  7. Write merged vectors to FITS.Écrire les vecteurs fusionnés dans un fichier FITS.

Velocity correctionCorrection de vitesse

S1D-Rama automatically reads the barycentric Earth radial velocity (BERV) and target systemic velocity from the FITS header and computes a rest-frame flux on the common wavelength grid. S1D-Rama lit automatiquement la vitesse radiale barycentrique terrestre (BERV) et la vitesse systémique de la cible dans l'en-tête FITS, puis calcule un flux au repos sur la grille de longueur d'onde commune.

Header keywordMot-clé d'en-têteExtensionExtensionMeaningSignification
BERVext 1Barycentric Earth radial velocity (km/s)Vitesse radiale barycentrique terrestre (km/s)
ESO TEL TARG RADVELext 0Target systemic velocity (km/s)Vitesse systémique de la cible (km/s)
Relativistic Doppler correction: β = vtotal/c, doppler_factor = √[(1 − β)/(1 + β)]. The flux is then interpolated: flux_zerovel(λ) = flux(λ / doppler_factor). Both the observed and rest-frame fluxes are written on the same wavelength grid, enabling direct co-addition and template matching across epochs. Correction Doppler relativiste : β = vtotal/c, doppler_factor = √[(1 − β)/(1 + β)]. Le flux est ensuite interpolé : flux_zerovel(λ) = flux(λ / doppler_factor). Les flux observé et au repos sont tous deux écrits sur la même grille de longueur d'onde, ce qui permet une co-addition directe et un appariement de gabarits (template matching) entre époques.

Fidelity vs. full APERO pipelineFidélité par rapport au pipeline APERO complet

S1D-Rama reproduces the merge logic from APERO's e2ds_to_s1d function. It is intentionally a standalone implementation and does not run the full APERO reduction chain (calibrations, extraction, telluric recipes, database interactions, etc.). S1D-Rama reproduit la logique de fusion de la fonction e2ds_to_s1d d'APERO. Il s'agit délibérément d'une implémentation autonome, qui n'exécute pas la chaîne de réduction APERO complète (calibrations, extraction, recettes telluriques, interactions avec la base de données, etc.).
